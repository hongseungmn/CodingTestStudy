# 02. 스택(Stack), 큐(Queue), 덱(Deque)의 원리와 실전 활용

> **핵심 키워드**: LIFO, FIFO, Monotonic Stack(단조 스택), `ArrayDeque` vs `LinkedList`, `Stack` 클래스 쓰지 말아야 하는 이유

---

## 1. 세 자료구조의 기본 개념과 시간 복잡도

모든 연산(삽입, 삭제, 조회)의 핵심은 **$O(1)$**입니다.

| 자료구조 | 정책 | 핵심 연산 | 시간 복잡도 | 실생활 비유 |
| :--- | :--- | :--- | :--- | :--- |
| **스택 (Stack)** | **LIFO** (Last In First Out, 후입선출) | `push()`, `pop()`, `peek()` | 모두 $O(1)$ | 프링글스 감자칩 통, 웹 브라우저 뒤로가기 |
| **큐 (Queue)** | **FIFO** (First In First Out, 선입선출) | `offer()` / `add()`, `poll()` / `remove()`, `peek()` | 모두 $O(1)$ | 은행 번호표 창구 줄서기, 프린터 인쇄 대기열 |
| **덱 (Deque)** | 양방향 입출력 (Double-Ended Queue) | `offerFirst()`, `offerLast()`, `pollFirst()`, `pollLast()` | 모두 $O(1)$ | 양쪽이 뚫린 기차 터널, 슬라이딩 윈도우 |

## 2. ⚠️ Java 코딩테스트 주의사항: `java.util.Stack`은 절대 쓰지 마라?

### 왜 `Stack<Integer> stack = new Stack<>();`을 쓰지 말아야 할까?
1. **레거시 클래스 (Java 1.0 출신)**: `Vector` 클래스를 상속받아 구현됨.
2. **불필요한 동기화 오버헤드 (`synchronized`)**: 모든 메서드에 락이 걸려 코딩테스트 환경에서 불필요한 성능 저하 유발.
3. **객체지향 설계 원칙 위반**: `stack.get(3)`, `stack.add(1, 50)`처럼 인덱스로 중간 요소를 조작할 수 있어 LIFO 대원칙 훼손.

### 💡 공식 권장 정답: `Deque` 인터페이스 + `ArrayDeque`
```java
// ⭕ 강력 추천 (빠르고 가벼움)
Deque<Integer> stack = new ArrayDeque<>();
stack.push(10);
stack.pop();
stack.peek();
```

## 3. `Queue` 메서드의 예외 발생 vs 특별한 값 반환

| 연산 | 실패 시 **예외(Exception)** 발생 | 실패 시 **특별한 값(`false` / `null`)** 반환 |
| :--- | :--- | :--- |
| **삽입 (Insert)** | `add(e)` | `offer(e)` |
| **삭제 (Remove)** | `remove()` | `poll()` |
| **조회 (Examine)** | `element()` | `peek()` |

### 🧠 알고리즘 접근 및 복잡도 분석

1. **접근 1: 스택(ArrayDeque)을 활용한 정석 풀이**
   - 여는 괄호 `(`를 만나면 `stack.push('(')`
   - 닫는 괄호 `)`를 만나면 `stack.pop()`으로 상쇄. 만약 비어있다면 바로 `false`
   - 순회 후 `stack.isEmpty()` 여부 반환
   - **시간 복잡도**: $O(N)$ (길이 100,000을 1회 순회)
   - **공간 복잡도**: $O(N)$ (최악의 경우 스택에 10만 개 저장)

2. **접근 2: 공간 최적화 풀이 (카운터 변수 활용)**
   - 괄호의 종류가 `()` 하나뿐일 때는 굳이 스택 객체를 만들지 않고, **스택의 크기(size)**만 `int count`로 추적
   - `(` 만나면 `count++`, `)` 만나면 `count--`
   - 도중에 `count < 0`이 되는 순간 즉시 `false`
   - 순회 후 `count == 0` 여부 반환
   - **시간 복잡도**: $O(N)$
   - **공간 복잡도**: **$O(1)$** (변수 하나로 추가 메모리 거의 없음)
